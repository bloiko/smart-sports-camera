# Smart Sports Camera — прототип v0.2

Перетворює широке відео гри з нерухомої камери на ролик 1920×1080, який слідує за грою.

## Як це працює

1. `src/detect.py` — шукає гравців і м'яч (YOLO11s, COCO) на кожному N-му кадрі, ділячи панораму на 3 плитки.
2. `fieldmask.py` — автоматично знаходить поле (зелена трава), щоб відкинути глядачів і людей за полем.
3. `follow.py` — віртуальна камера:
   - центр гри = зважений центр гравців (ближчі до групи важать більше);
   - зум залежить від розкиду гравців і глибини (далекий бік — сильніший зум);
   - мертва зона, двостороннє згладжування, обмеження швидкості панорамування;
   - рендер `out_follow.mp4` (результат) і `out_debug.mp4` (панорама з рамкою камери);
   - `metrics.json` — метрики якості.
4. `ball_motion.py` — експеримент: пошук м'яча за рухом. **Поки не працює** (ловить тіні й блиск трави), не використовується.

## Запуск на Mac (M1/M2)

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
brew install ffmpeg

python src/detect.py game.mp4 detections.jsonl 5     # кожен 5-й кадр
python src/follow.py game.mp4 detections.jsonl out   # створює out/out_follow.mp4
```

На Mac можна прискорити детекцію, додавши `device='mps'` у `m.predict(...)` в `src/detect.py`.

## Параметри

Усе, що варто крутити, — у словнику `CFG` на початку `follow.py`
(зум, згладжування, швидкість камери, мертва зона, глибина поля).
`depth_y` треба підібрати під свою камеру: y-координата дальньої і ближньої бровки.

## Відомі обмеження v0.1

- Готова модель YOLO бачить ігровий м'яч лише в ~13% відліків — коли він на ближній половині поля. На дальньому боці м'яч займає 5–8 пікселів і не знаходиться. Запасні м'ячі біля бровки відфільтровано як нерухомі. Тому камера переважно стежить за групою гравців, а м'яч лише уточнює кадр, коли знайдений. Рішення — фаза 2: дотренувати модель на розмічених кадрах.
- Результати v0.1 на тестовому відео (4 хв SoccerTrack v2): м'яч у кадрі 94% часу, коли знайдений; 72% гравців поля в кадрі; макс. швидкість панорамування 363 px/с. Повні метрики — `metrics.json`.
- Ліцензія: Ultralytics YOLO — AGPL-3.0. Для прототипу ок, для закритого продукту — перейти на RF-DETR / D-FINE / YOLOX (Apache 2.0).

## v0.2: м'яч на дальньому боці (без ручної розмітки)

1. `ball_window.py` — пошук м'яча у 2x збільшеному вікні навколо кадру камери з першого проходу.
2. `make_dataset.py` — автоматична розмітка: упевнені детекції + проміжні кадри, де позицію м'яча обчислено з траєкторії.
3. `train.py` — дотренування YOLO11n (патчі 320 px, CPU, ~35 хв). Результат — `ball_v02.pt`.
4. Повторний прохід `ball_window.py` з `BALL_MODEL=ball_v02.pt`, потім `follow.py ... --balls ball_v02.jsonl`.

Результат на останніх 20% відео (модель їх не бачила при навчанні):
м'яч знайдено у 40% відліків проти 19% у готової моделі. М'яч у кадрі камери — 98% часу, коли знайдений.
Застереження: навчено й перевірено на одному матчі, на іншому полі цифри будуть нижчими.
