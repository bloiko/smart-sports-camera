# Specs (frequently changing)

Update these at the end of every work session. Stable documents are in [`../docs/`](../docs/README.md).

| File | Contents | Update when |
| --- | --- | --- |
| [status.md](status.md) | Per phase: status, done, to do, difficulties, lessons learned | Any work finished or blocked |
| [backlog.md](backlog.md) | Prioritised open work with problem, ideas and "done when" | New issue, feedback, or priority change |
| [results.md](results.md) | Metrics per version and match, precision checks, goal checklist | Every pipeline run worth keeping |
| [datasets.md](datasets.md) | Test videos, generated data, models | New video or model |
| [metrics/](metrics/) | Raw `metrics.json` files from notable runs | Optional, for exact numbers |
